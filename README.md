# Toplu Yatırım - Portföy Takip Micro SaaS

Toplu Yatırım, finansal varlıklarınızı tek bir noktadan yönetmenizi sağlayan modern ve hızlı bir tek sayfalık web uygulamasıdır (SPA).

## Özellikler
- 🚀 **Hızlı ve Modern Arayüz:** Tailwind CSS ile geliştirilmiş cam efekti (glassmorphism) barındıran şık tasarım.
- 🔐 **Kullanıcı Yönetimi:** LocalStorage tabanlı oturum yönetimi simülasyonu.
- 📊 **Portföy Yönetimi:** Varlık ekleme, güncelleme ve satış işlemleri için özel formlar ve sürükle-bırak (Drag&Drop) dosya yükleme alanı.
- 💰 **Dinamik Hesaplama:** Güncel varlık değerlerinin anında hesaplanıp tabloya yansıtılması.

## Teknolojiler
- HTML5
- Vanilla JavaScript
- Tailwind CSS (CDN)
- FontAwesome Icons

## Kurulum
1. Projeyi bilgisayarınıza indirin veya klonlayın.
2. `index.html` dosyasını tarayıcınızda açmanız yeterlidir. Herhangi bir sunucu kurulumuna gerek yoktur.
